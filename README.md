# 부정적분 스피드

∫f(x)dx를 보고 부정적분을 고르는 스피드 게임과 랭킹입니다.

- 학생용: `사이트주소/`
- 선생님용: `사이트주소/teacher/` (비밀번호 필요)

## 게임 규칙

- 문제: "∫(…) dx — 부정적분을 구하시오. (단, C는 적분상수)"
- 보기 4개, 정답 1개. 모든 보기에 + C가 붙어 있고, 보기를 누르면 바로 채점합니다.
- 레벨을 골라 시작합니다. 레벨마다 12문제이며, 문제는 매번 새로 만들어집니다.
  - 레벨 1: 항 1개, 피적분함수 1~3차 (부정적분은 4차까지) · 점수 ×1
  - 레벨 2: 항 2개, 피적분함수 최고차항 1~4차 · 점수 ×1.5
  - 레벨 3: 항 3개, 피적분함수 최고차항 2~5차 · 점수 ×2
  - 한 판 안에서 최고차항의 차수가 고르게 나옵니다 (레벨 1은 1·2·3차 4문제씩, 레벨 2·3은 차수마다 3문제씩).
- 한 문제당 기본 15초입니다.
- 점수: (정답 100 + 남은 시간 최대 100 + 콤보 최대 50) × 레벨 배율

## 보기 구성

정답 F(x) + C에서 부호·계수·차수 중 하나만 바꿔 오답을 만듭니다.
- 부호: 한 항의 부호, 또는 모든 항의 부호가 바뀜
- 계수: 한 항(또는 모든 항)을 올린 지수로 나누지 않음, 나누지 않고 곱함
- 차수: 한 항의 지수를 올리지 않음, 2만큼 올림, f(x)를 미분함(일부 문제)
- 모든 보기는 미분해서 f(x)가 되는지로 정답 여부를 자동 확인합니다.
- 틀리면 보기마다 왜 정답·오답인지 이유가 나오고, 결과 화면에서 틀린 문제를 다시 볼 수 있습니다.

## 랭킹

- 학생은 시작할 때 학급(예: 3반)과 이름을 입력합니다.
- 같은 창에서 다시 도전하면 같은 학생으로 보고 레벨마다 최고 기록만 남깁니다.
  창을 닫거나 새로고침한 뒤 다시 들어오면 학급·이름이 같아도 새 기록으로 따로 올라갑니다. 이런 중복은 선생님 화면에서 삭제하세요.
- 레벨별 랭킹: 레벨 1·2·3을 따로 매깁니다.
- 종합 랭킹: 학생마다 레벨 1·2·3 최고 기록(배율 적용 점수)을 더한 점수로 매깁니다.
- 학생 화면: 레벨 1 / 레벨 2 / 레벨 3 / 종합 탭으로 보입니다. 보이는 인원은 선생님 화면의 "학생 화면 랭킹 인원"에서 레벨별·종합 따로 정합니다(기본 10명, 1~100명).
- 선생님 화면: 같은 탭으로 잘리지 않고 모든 학생이 학급과 함께 보입니다. 레벨 탭에서는 "학생별 최고 기록"과 "모든 기록"을 바꿔 볼 수 있습니다.
- 기록 삭제·복구: 레벨 탭의 기록마다 "삭제" 버튼이 있습니다. 삭제한 기록은 학생 화면과 모든 랭킹에서 바로 빠지고,
  그 학생의 다음 기록이 최고 기록이 됩니다. 기록은 지우지 않고 숨겨 두므로 "삭제된 기록" 목록에서 하나씩 "복구"할 수 있습니다.
- "PDF로 저장"을 누르면 종합·레벨 1·레벨 2·레벨 3 랭킹 전체(삭제한 기록 제외)가 한 문서로 정리되어 인쇄 창이 열립니다. 대상에서 "PDF로 저장"을 고르세요.
- 랭킹은 제한시간별로 따로 쌓입니다. "랭킹 초기화"는 삭제된 기록까지 모두 완전히 지웁니다(되돌릴 수 없음).

## 배포 순서 (처음 한 번)

1. GitHub에서 새 저장소(예: `integral-speed`)를 만들고, 이 폴더의 내용물(`src`, `netlify`, `build.mjs`, `netlify.toml`, `package.json`, `README.md`)을 올립니다.
2. 넷리파이 → Add new project → Import an existing project → GitHub → 새 저장소 선택 → Deploy
3. Project configuration → Environment variables → `TEACHER_PASSWORD` 등록 (Contains secret values 켜기)
4. Deploys → Trigger deploy → Deploy project 로 한 번 다시 배포
5. Make public 으로 공개
